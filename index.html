識別顏色
黃色(預設)

盲道唔係標準黃色?喺畫面入面點一下盲道,就會改為識別嗰隻顏色。認錯太多就將靈敏度拉向「嚴格」,認漏就拉向「寬鬆」。

一下=左 兩下=右 三下=前面有變 長震=未見到

AI 助手(DeepSeek)

開咗之後,講「你好小程序,前方有咩?」,就會影低而家個畫面問 AI,再讀出答案。要容許用咪;語音識別由瀏覽器提供,Chrome 會經 Google 伺服器處理。

DeepSeek API Key未設定

Key 只會存喺呢部機嘅瀏覽器,唔會上傳到 GitHub。問問題時,畫面相片會傳去 DeepSeek 分析。冇 Key 都用得,但只會講盲道位置。

呢個係輔助工具,靠顏色認盲道,夜晚黃燈、黃色路線、褪色或者非黃色盲道都可能認錯或者認漏;AI 嘅回答亦可能有錯。唔可以取代白杖或者導盲犬。
